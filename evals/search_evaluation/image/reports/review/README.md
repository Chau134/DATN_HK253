# Canonical Ground-Truth Review Artifacts

This directory preserves the completed visual-review evidence for the canonical 2026-08-22
Image Search run.

- `ground_truth_image_review_completed.csv`: completed review export.
- `ground_truth_image_review_overrides.csv`: explicit reviewer overrides.
- `image_ground_truth_review_completed.html`: frozen visual-review interface.

The finalized canonical ground truth remains at `../../data/ground_truth_image.csv`. These review
artifacts are retained for auditability and can be regenerated by the scripts under `../../scripts/`.
