# Simple Image Condition

Điều kiện `simple` gồm 100 ảnh catalog và là nửa đối chứng của phép kiểm tra độ
bền Image Search. Artifact chính thức nằm trực tiếp trong `reports/`, gồm metric
similarity, exact match, latency và paired comparison. Thư mục pooling/review
trung gian đã được loại bỏ sau khi khóa kết quả.
